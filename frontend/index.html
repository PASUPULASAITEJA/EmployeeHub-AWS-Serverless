Help & About

Learn about EmployeeHub and how to use it.

About EmployeeHub

EmployeeHub is a serverless employee registration system built on AWS. It replaces manual paper-based employee onboarding with a secure, scalable digital workflow. The application uses Amazon S3 for frontend hosting, API Gateway for routing, AWS Lambda for business logic, and Amazon DynamoDB for the employee database.

Registering Employees

Go to Register Employee and fill in the required fields. Employee ID must be unique. After submission, the record is saved to DynamoDB.

Searching & Filtering

Use the search box on the All Employees page to find records by name or ID. Combine with department and employment type filters.

Dashboard Statistics

The dashboard shows total employees, active departments, and recent joiners — all calculated from live API data.

Deployment

Deploy with AWS SAM: sam build then sam deploy --guided. The frontend is hosted on S3 + CloudFront.

Security

AWS credentials never touch the browser. Input is validated on both client and server. CORS is restricted to the frontend origin.

Data Storage

Employee records are stored in DynamoDB with employeeId as the partition key. Conditional writes prevent duplicates.
